Your home in 3D, built by talking to Claude

Big Bang Planner is a free framework for interactive 3D models of homes. Give Claude a floor plan and one real measurement: it writes the house as plain data in metres, and you get a model you can walk through, measure and print as a dimensioned plan.

Download on GitHub Try the example

No install and no build step: plain HTML, JavaScript and three.js.

Explore the example

Apartment 4A, inspired by Sheldon and Leonard's flat. Open the doors, switch on the computers, run the taps or walk inside.

The layout and measurements are made up for the example; they do not reproduce the plans of the set.

How it works

The engine is already written. For each home, Claude only writes a data file, and checks it with you against reality.

Share the plan

Give Claude an image or PDF of the floor plan and one real measurement of a long wall: that sets the scale.

Claude builds the house

Walls, doors, windows and rooms go into one file, houses/<name>/house.js, in metres. The dimensioned plan lets you check every room against your own measurements.

Furnish and share

Room by room, from photos or from what you tell it. Then publish it as a private claude.ai Artifact or put it on any static host.

What you can do with it

Everything in the example comes with the framework, for any house.

Walk through it

First person with keyboard and mouse. You climb steps; walls, furniture and closed doors block the way.

Use things

Doors, wardrobes, drawers and the fridge open; taps run with sound; computers, TV, oven and lamps switch on.

Measure anything

Two clicks on any floor, wall or piece of furniture give the distance, in plan and in height.

Dimensioned 2D plan

Interior dimensions of every room, door swings and windows, ready to print.

One room at a time

Double-click a room to see it on its own, and lower the walls to see the furniture from above.

29 pieces, all procedural

Sofas, beds, a kitchen with a real sink cut-out, a full bathroom… Drawn in code: no textures or models to license.

English and Spanish

The viewer follows the browser's language, and each house can carry its texts in both.

Phones and tablets

Drag to rotate, pinch to zoom, press and hold to see a room on its own.

A house is just data

No engine code to touch: one plain file per house, in metres, with x to the east and y to the south, as on a drawing. Doors and windows cut the walls on their own. Missing a piece of furniture? Define it in the same file.

Read the format 
export default {
  name: { en: 'My flat', es: 'Mi piso' },
  ceilingHeight: 2.6,
  walls: [
    [0, 0, 8, 0.25],          // 8 m long, 25 cm thick
    [3, 0.25, 3.1, 4],        // a partition
  ],
  doors: [
    { opening: [1.2, 0, 2, 0.25], type: 'swing',
      opensTo: 'south', hinges: 'west' },
  ],
  rooms: [
    { name: 'Living room', floor: 'wood',
      polygon: [[0.25, 0.25], [3, 0.25], [3, 4], [0.25, 4]] },
  ],
  furniture: [
    { type: 'sofa', x: 1.6, y: 3.5, facing: 'north' },
    { type: 'desk', x: 0.6, y: 1.2, facing: 'east', screens: 2 },
  ],
};

Get started

Free under the MIT licence. Download it once and use it for as many homes as you like.

As a Claude skill

Copy the folder to ~/.claude/skills/bigbangplanner/ and ask Claude, with the plan attached: “Use bigbangplanner to build my flat from this plan. The living room wall is 4.20 m long.”

Download ZIP

On your computer

Clone it and serve the folder with any static server, then open the viewer.

git clone https://github.com/darkspock/bigbangplanner.git
cd bigbangplanner
python3 -m http.server 8000
# http://localhost:8000/viewer.html
