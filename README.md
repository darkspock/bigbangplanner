# Big Bang Planner

*[Leer en español](README.es.md)*

A free, open-source framework (MIT) for interactive 3D models of homes.

Turns the floor plan of a home into an interactive 3D model in the browser, by talking to Claude: you give it the plan, a few measurements and photos, and it gives you back the house in 3D, furnished, where you can:

- **look at it** whole or from above, and lower the walls;
- **see a single room** (double-click its floor; on a phone, press and hold);
- **walk** through it in first person and use things: open doors, wardrobes, drawers and the fridge, run the taps, switch on the computers, the TV, the oven, the hob or the lamps;
- **measure** any distance with two clicks;
- get a **scaled 2D plan** with each room's interior dimensions, doors with their swing and windows, and print it.

The **?** button in the panel (or the ? key) explains how to move around with mouse, keyboard and touch screen.

The interface is in **English and Spanish**: it follows the browser's language, and the flags in the panel switch it (or add `?lang=en` / `?lang=es` to the address).

Nothing to install and no programming: the house is a data file in metres that Claude writes.

## How to use it

Download it from GitHub (`git clone https://github.com/darkspock/bigbangplanner.git`, or the ZIP from the repository page).


1. Install the folder as a Claude skill. In Claude Code, for example, by copying it to `~/.claude/skills/bigbangplanner/` (`SKILL.md` is at the root).
2. Ask Claude with the plan attached: *"Use bigbangplanner to build my flat from this plan. The living room wall is 4.20 m long."*
3. Claude builds walls, doors, windows and rooms, shows you the Plan with the dimensions so you can compare them with the real ones, and then furnishes the house room by room with you.
4. To share it, Claude publishes it as a private claude.ai Artifact, and you decide who to share it with.

## View it on your computer

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000/` (the project's landing page, with the example embedded), `http://localhost:8000/viewer.html` (the example house) or `http://localhost:8000/viewer.html?house=<name>`.

## What is inside

| Folder | Contents |
|---|---|
| `engine/` | The engine: scene, walls and openings, pieces, walk, 2D plan, languages and styles. The same for every house. |
| `houses/` | One folder per house with its `house.js`. Comes with `apartment-4a` as an example. |
| `index.html` | The project's landing page. |
| `viewer.html` | The viewer: opens a house in 3D. |
| `docs/FORMAT.md` | The house format and the list of pieces. |
| `SKILL.md` | The instructions for Claude. |

## The example house

`apartment-4a` is a fan homage inspired by Sheldon and Leonard's apartment in the TV series *The Big Bang Theory*. The layout and measurements are made up and approximate, not official plans. The series, its characters and its name belong to their owners. No images or logos from the series are used: everything is drawn by the kit itself.
